\begin{abstract}
This monograph defines a general relational tensor--scalar,
orbital--fractal algebra prior to any specific spacetime, metric, or physical
interpretation. The core signature contains relational admissibility, a
minimal point carrier, additive typed sectors, relational and tensor
products, contraction, typed transport, semantic coarse-graining, orbital
operators, and recursive branch refinement. Associativity, commutativity,
bilinearity, functoriality, equivariance, monoidality, and cross-operation
naturality are not silently imposed; their failures are retained as explicit
residuals.

Projective \(\CP\)/Fubini--Study geometry, scalar-angle Moir\'e rotation,
generic \(U(1)\) phase tools, and the Zero-Axis projective map are separated
from the core as reference realizations or bridge structures. In particular,
the recursive \(\CP\) construction is fibre-local rather than one global
Bloch sphere, and a phase representation of abstract relational holonomy must
be supplied by a concrete realization before the Zero-Axis lift is used.

The current canonical foundational stratification is
\(\mathrm{META0}\triangleright(\mathrm{RA0}+\mathrm{RR1})\);
the stronger object-level closure candidate \(\mathrm{RA0}^{*}\) is tracked
separately. No Planck scale, Minkowski structure, gravitational law, exact
self-similarity, or physical identification is assumed by the general
algebra.
\end{abstract}

\section{Scope}

The object developed here is not a spacetime model. It is a general algebra
of relations. Concrete geometric and physical constructions may later be
representations of this algebra, but they are not part of its definition.

The typed algebraic family is written
\[
\boxed{
\Arel=\left\{\mathcal A_{\sigma,\omega}^{p,q}\right\},
}
\]
where \((p,q)\) is tensor rank, \(\omega\in\{-1,+1\}^{*}\) is the exact
path-labelled relational carrier address, and \(\sigma\in\Sigma\) is a semantic
scale or context. The refinement level is derived as \(n=|\omega|\); two
different addresses at the same level remain different typed sectors.

The scalar sector is not a separate ontology. It is the tensor rank-zero
sector:
\[
\boxed{
\mathbb K_{\sigma,\omega}=\mathcal A_{\sigma,\omega}^{0,0}.
}
\]

\section{Model formation: non-reification and non-vacuity}

Before the object-level relational axioms, RTOFA fixes the class of admissible
models.

Absolute nothingness is not assigned a term, carrier, state, value, relation,
zero, or set inside the object language. In particular, the mathematical
empty set \(\varnothing\) is not identified with absolute nothingness:
\(\varnothing\) is already a mathematical object.

The model-formation meta-axiom is therefore

\[
\boxed{
\mathrm{META0}:
\begin{cases}
\text{absolute nothingness has no denotation in the RTOFA object language},\\[1mm]
\mathfrak M\in\operatorname{Mod}(\mathrm{RTOFA})
\Rightarrow
\operatorname{Adm}^{\mathfrak M}\neq\varnothing.
\end{cases}
}
\]

META0 is not a proposition about an object called ``nothing.'' It specifies
what counts as an RTOFA model.

Consequently every admissible model satisfies

\[
\boxed{
\mathrm{EX0}:
\exists p\,\operatorname{Adm}(p).
}
\]

Thus

\[
\boxed{
\mathrm{META0}\models\mathrm{EX0}.
}
\]

EX0 is classified as a theorem of model-formation semantics rather than an
additional object-level ontological axiom.

A raw empty mathematical presentation remains useful as a metamathematical
vacuity witness. Universal formulas may hold there vacuously, but that raw
presentation is excluded from \(\operatorname{Mod}(\mathrm{RTOFA})\).

\section{Relational admissibility}

The motivating relational intuition is: if absolutely nothing is admitted,
there is no admitted term that can stand in relation to another and therefore
no admitted observation can be formed. The formal kernel does not quantify
over a metaphysical object called ``nothing.'' It records only the operational
consequence relevant to the algebra: anything admitted as an observable is
not independent of relation.

Accordingly, the foundational rule is stated as the admissibility condition:
\[
\boxed{
\operatorname{Adm}(x)
\Longrightarrow
\exists\,y,r:
\left(
\operatorname{Rel}_{r}(x,y)
\lor
\operatorname{Rel}_{r}(y,x)
\right).
}
\tag{RA0}
\]
An admissible observable is therefore not defined as an isolated object.
The statement is intentionally weaker and cleaner than a physical claim: it
does not assign a spacetime, energy, length, or dynamics.

\subsection{Relational-admissibility reduction gate}

META0 does not by itself imply RA0 when \(\operatorname{Adm}\) is treated as
a primitive predicate. The finite presentation
\[
P=\{a\},
\qquad
\operatorname{Adm}=\{a\},
\qquad
R=\varnothing
\]
is non-empty but leaves \(a\) incident to no primitive relation. Hence
\[
\boxed{
\mathrm{META0}\not\Rightarrow\mathrm{RA0}
}
\]
under the current primitive-admissibility language.

There is a possible definitional reduction. One may instead define
\[
\boxed{
\operatorname{Adm}_{R}(x)
:\Longleftrightarrow
\exists y,r\,
\left(
\operatorname{Rel}_{r}(x,y)
\lor
\operatorname{Rel}_{r}(y,x)
\right).
}
\]
Under this definition RA0 becomes true by definitional expansion and need not
remain an independent axiom.

This is not a theorem from the old language. It changes the semantics of
admissibility: isolated carriers become inadmissible by definition. The
current kernel therefore keeps primitive \(\operatorname{Adm}\) and RA0 as
an axiom until that definitional reduction is explicitly promoted.

A primitive relation is typed as a binary arrow
\[
\boxed{r:a\to b.}
\]
This is a definition of the primitive relational signature, not a theorem of
RA0. Higher-arity relations may be constructed separately from binary
relations or introduced by an explicit extension of the signature.

The absence of an admitted relation is not identified with algebraic zero.
For every typed sector there may be a zero element
\[
0_{\sigma,\omega}^{p,q}\in\mathcal A_{\sigma,\omega}^{p,q},
\]
while ``no relation'' is a separate condition.
In the additive reference sector this zero is executable as the identity
\[
X+0_X=X,
\qquad
X-X=0_X.
\]
The zero \(0_X\) is sector-exact: it carries the same tensor rank, exact
relational carrier, semantic scale, and component dimension as \(X\).
Its refinement level is derived from that carrier and does not by itself
identify the additive sector.
The executable reference zero of an element preserves its rank, carrier,
semantic scale, and component dimension.

\subsection{Formula-level vacuity versus admissible-model semantics}

RA0 is conditional on an observable being admitted, and RR1 is conditional on
a relational occurrence being available to refine. Therefore, if those

Accordingly, at the formula level,

\boxed{

This does not contradict META0. The empty presentation is a mathematical

Within the intended model class,

\[

\]

Hence the foundational stratification is

\[
\boxed{
\mathrm{META0}
\;\triangleright\;

with EX0 derived from model formation.

\section{Minimal carrier and minimal distinction}

The minimal carrier of the general algebra is a point
\[
\boxed{p.}
\]
No Planck length or other physical scale is attached to it at this level.
A later physical representation may provide such a scale through a separate
bridge.

The reference minimal two-channel realization of a distinction uses a
non-zero vector in \(\mathbb C^2\), modulo global phase:
\[
|\psi\rangle
=\alpha|0\rangle+\beta|1\rangle,
\qquad
|\alpha|^2+|\beta|^2=1,
\]
\[
\boxed{
\mathbb P(\mathbb C^2)=\CP\simeq S^2.
}
\tag{REF-CP1}
\]
The natural projective metric is Fubini--Study:
\[
\boxed{
d_{\FS}([\psi],[\phi])
=\arccos|\langle\psi|\phi\rangle|.
}
\]

A relation \(r\) may select two projective states
\[
r\longmapsto(p_r^-,p_r^+)\in\CP\times\CP.
\]
For this pair to realize a binary distinction faithfully, the projective
states must be distinct:
\[
\boxed{
d_{\FS}(p_r^-,p_r^+)>0.
}
\]
This geometric non-degeneracy is separate from carrier-label multiplicity.
The two branch occurrences may carry the same underlying carrier label while
their local projective states remain distinct.

Maximal distinction is the special case
\[
\langle p_r^-|p_r^+\rangle=0,
\qquad
d_{\FS}=\frac{\pi}{2}.
\]
Generic distinctions need not be maximal and therefore need not select
antipodal Bloch points, but zero Fubini--Study separation is rejected by the
reference distinction realization. Equation (REF-CP1) is a reference realization of a
complex binary distinction. It is not claimed to follow from RA0 alone.

\section{Recursive relational refinement}

A selected relational point may itself become the carrier of another
minimal distinction. Let
\[
V_n=\{-1,+1\}^{n}.
\]
For \(\omega\in V_n\), define the binary refinement
\[
\boxed{
p_\omega\longmapsto
\{p_{\omega-},p_{\omega+}\}.
}
\tag{RR1}
\]
The two children are non-degenerate as \emph{occurrences}: their path
addresses \(\omega-\) and \(\omega+\) are distinct. This does not require
their underlying carrier labels to be different. In particular, the
singleton presentation
\[
D(a)=(a,a)
\]
is permitted: \(a_-\) and \(a_+\) are different relational occurrences
even though
\[
\operatorname{carrier}(a_-)
=
\operatorname{carrier}(a_+)
=
a.
\]
RR1 is an explicit second foundational axiom: RA0 requires relation but does
not by itself force recursive refinement. Thus the general construction contains a recursive relational tower
\[
p\to\{p_-,p_+\}
\to\{p_{--},p_{-+},p_{+-},p_{++}\}
\to\cdots.
\]

Fractality means compatibility across refinement levels, not a requirement of
perfect geometric self-similarity. For a branch
\(\epsilon\in\{-1,+1\}\), use the typed refinement
\[
\boxed{
F_{\epsilon}:
\mathcal A_{\sigma,\omega}^{p,q}
\to
\mathcal A_{\tau,\omega\epsilon}^{p,q}.
}
\]
The target semantic scale \(\tau\) is explicit; the reference realization
preserves tensor rank and advances the relational carrier by exactly one
branch. For a relational product \(\star\), define
\[
\boxed{
\Delta_{F_{\epsilon}}(X,Y)
=
F_{\epsilon}(X\star Y)
-
F_{\epsilon}(X)\star F_{\epsilon}(Y).
}
\]
Exact self-similarity is the special case \(\Delta_F=0\). Non-zero residuals
remain legitimate algebraic information.

\subsection{Reference CP1 fibre realization of refinement}

The recursive relation admits a concrete projective reference realization
without promoting \(\CP\) to a universal axiom. Associate to each relational
carrier a local fibre
\[
\boxed{
\mathcal F_{\omega}\simeq\CP
}
\]
with its Fubini--Study metric. A local distinction
\[
D_{\omega}
=
\left(
q_{\omega-},q_{\omega+}
\right),
\qquad
q_{\omega\pm}\in\mathcal F_{\omega},
\]
indexes the two child carriers
\[
p_{\omega-},
\qquad
p_{\omega+}.
\]
Each child carrier may then support its own local fibre
\[
\mathcal F_{\omega-}\simeq\CP,
\qquad
\mathcal F_{\omega+}\simeq\CP.
\]

The selected projective state \(q_{\omega\pm}\) in the parent fibre is
not identified with a coordinate in the child fibre. The connection is an
incidence/refinement relation:
\[
q_{\omega\pm}
\rightsquigarrow
p_{\omega\pm}
\rightsquigarrow
\mathcal F_{\omega\pm}.
\]
This avoids treating all refinement levels as points on one global Bloch
sphere.

The executable maximal reference tree chooses an orthogonal pair in every
local fibre,
\[
d_{\FS}(q_{\omega-},q_{\omega+})=\frac{\pi}{2},
\]
but non-maximal local distinctions are also admissible. Hence maximal
antipodality belongs to one reference subclass, not to the general relational
axiom.

\section{Tensor--scalar grading and typed relations}

Each typed sector carries an additive module structure over a scalar domain \(\mathbb K\):
\[
\boxed{
(\mathcal A_{\sigma,\omega}^{p,q},+,0,-,\mathbb K\curvearrowright\mathcal A_{\sigma,\omega}^{p,q}).
}
\]
The abstract algebra does not fix \(\mathbb K=\mathbb C\); the reference kernel uses complex components. This additive structure is required before expressions such as commutators, associators, and refinement residuals can be formed as differences.

Elements are typed by tensor rank, semantic scale, and exact relational carrier address:
\[
X\in\mathcal A_{\sigma,\omega}^{p,q}.
\]
The level \(n=|\omega|\) is derived metadata and is not sufficient to identify the additive sector.
Tensor product and contraction have the schematic types
\[
\otimes:
\mathcal A_{\sigma,\omega}^{p,q}\times
\mathcal A_{\tau,\eta}^{r,s}
\to
\mathcal A_{\upsilon,\zeta}^{p+r,q+s},
\]
\[
\operatorname{Contr}:
\mathcal A_{\sigma,\omega}^{p,q}
\to
\mathcal A_{\sigma,\omega}^{p-1,q-1},
\]
whenever the relevant type and relation constraints are satisfied.

The tensor product itself is supplied as a typed rule; the reference
Kronecker-style implementation is only one realization. Strict monoidal
properties are tested rather than assumed. Define
\[
\boxed{
\Delta_{\alpha}^{\otimes}(X,Y,Z)
=
\left\|
(X\otimes Y)\otimes Z
-
X\otimes(Y\otimes Z)
\right\|
}
\]
for strict associativity. For explicitly supplied left and right unit
candidates \(\mathbf 1_L,\mathbf 1_R\),
\[
\boxed{
\Delta_{\mathbf 1}^{\otimes}(X)
=
\max\left(
\|\mathbf 1_L\otimes X-X\|,
\|X\otimes\mathbf 1_R-X\|
\right).

\]
For a supplied braiding \(\beta_{X,Y}\),
\[
\boxed{
\Delta_{\beta}^{\otimes}(X,Y)
=
\left\|
\beta_{X,Y}(X\otimes Y)-Y\otimes X
\right\|.
}
\]
The zero-defect reference subclass is strict with respect to these checks.

\section{Relational product: no premature associativity}

Let
\[
\star_R:
\mathcal A\times\mathcal A\to\mathcal A
\]
denote a relational product in a compatible typed sector. The current
foundation does not assume either commutativity or associativity.

Their failures are measured, not hidden:
\[
\boxed{
[X,Y]_{\star}
=X\star Y-Y\star X,
}
\]
\[
\boxed{
\alpha(X,Y,Z)
=(X\star Y)\star Z-X\star(Y\star Z).
}
\]
Commutative or associative subclasses are recovered when the corresponding
residual vanishes.

Bilinearity is also not silently assumed. Define the additive defects
\[
B_L^+(X,Y;Z)
=
(X+Y)\star Z-X\star Z-Y\star Z,
\]
\[
B_R^+(X;Y,Z)
=
X\star(Y+Z)-X\star Y-X\star Z,
\]
and scalar-linearity defects
\[
B_L^{\lambda}(X;Y)
=
(\lambda X)\star Y-\lambda(X\star Y),
\]
\[
B_R^{\lambda}(X;Y)
=
X\star(\lambda Y)-\lambda(X\star Y).
\]
Exact \(\mathbb K\)-bilinearity is therefore a zero-defect subclass:
\[
\boxed{
B_L^+=B_R^+=B_L^{\lambda}=B_R^{\lambda}=0.
}
\]
The general relational product may leave this subclass, in which case the
departure is recorded rather than hidden.

\subsection{Indexed tensor gate}

Therefore expressions such as

+
\text{pairing rule}
+
\text{component shape}
+
\text{contraction evaluator}.
}
\]
This is an explicit gate, not a missing axiom. Rank \((p,q)\) alone cannot

\section{Semantic scales}

Semantic scale is not assumed to be a single real parameter. Let
\[
\boxed{\sigma\in\Sigma}
\]
where \(\Sigma\) is a typed partially ordered or categorical scale
structure. A coarse-graining morphism is written
\[
S_{\sigma\to\tau}:
\mathcal A_{\sigma,\omega}^{p,q}
\to
\mathcal A_{\tau,\omega}^{p,q}.
\]
Such a map is admissible only when the scale structure contains the required
relation. This prevents unrelated semantic classes from being collapsed by
arithmetic alone.

A common semantic quotient of two types exists only when there is a common
admissible upper scale. Thus semantic compatibility is part of the algebraic
type system rather than an after-the-fact annotation.

The reference kernel implements these as executable typed maps. A scale map
must be admitted by the semantic scale graph, consume an element at its source
scale, and return an element at its declared target scale while preserving the
carrier and tensor rank in the reference realization.

\section{Relational deformation potential}

The semantic scale label \(\sigma\) does not by itself determine a scalar
deformation. A concrete semantic weighting profile is supplied separately.
Let a fixed named residual signature be

\[
D(X)=\{d_i(X)\}_{i\in I},
\qquad
d_i(X)\ge 0,
\]

and let the semantic profile at \(\sigma\) assign explicit non-negative
weights

\[
W_\sigma=\{w_{\sigma i}\}_{i\in I},
\qquad
w_{\sigma i}\ge0,
\]

with at least one positive weight. The weighting law is structural input; it
is not inferred from the string or label used to name \(\sigma\). Deriving
\(W_\sigma\) from a semantic graph or contextual relation system is a
separate open realization problem and is not part of the present algebraic
definition.

For \(p\ge1\), define the relational deformation potential

\[
\boxed{
V_R^{(p)}(X\mid\sigma)
=
\left(
\sum_{i\in I}
w_{\sigma i}\,d_i(X)^p
\right)^{1/p}.
}
\]

The residual signature is part of the type contract. A potential profile is
not allowed to silently add or omit a residual component.

If the residual vector \(D(X)\) and the potential order \(p\) are held fixed
while only the semantic weighting changes, then

\[
\boxed{
\Delta_{\sigma\to\tau}V_R(X)
=
V_R^{(p)}(X\mid\tau)
-
V_R^{(p)}(X\mid\sigma)
}
\]

isolates a semantic scalar deformation. Hence two evaluations can share the
same represented algebraic state and the same numerical residuals while
having different scalar relational potential because the supplied semantic
weighting differs. A change of \(p\) is not classified as a pure semantic
shift.

For a finite admissible candidate set \(\mathcal C\), define the relational
attractor set

\[
\boxed{
\operatorname{Attr}_R(\mathcal C)
=
\operatorname*{arg\,min}_{c\in\mathcal C}
V_R(c).
}
\]

Ties are preserved rather than resolved arbitrarily.

This construction is a scalar diagnostic of relational deformation. It is
not identified by the general algebra with energy, mass, gravity, or metric
curvature. A geometric realization may later supply a separate map such as

\[
\mathcal G:
V_R
\longmapsto
\delta g,

but that map is an additional realization/bridge and is not assumed here.

\section{Orbital action and relative Moir\'e structure}

=

\Delta_G(g,h;X)
=
\|U_{gh}X-U_g(U_hX)\|.

\[
\boxed{
\operatorname{Orb}(X)=\{U_gX:g\in G\}.

It is not an independent coordinate carried by \(X\).

\[
\boxed{

\tag{DER-M}

In a scalar-angle realization this reduces to the wrapped relative angle

\Delta\theta_{ij}

For a relative Moir\'e operator this specializes schematically to
\[
[M,S]=MS-SM.

A non-zero value is therefore a legitimate observable of the algebra rather
than an implementation error.

\section{Relational transport and two closure notions}

\subsection{Forgetful projection from occurrences to relation values}

A relation occurrence carries a typed relation value together with source and
target occurrence addresses,
\[
\widetilde r
=
(r,\omega_{\rm src},\omega_{\rm dst}).
\]
Define the forgetful projection
\[
\boxed{
\pi_{\rm occ\to val}
(\widetilde r)
=
r.
}
\]
For an occurrence-aware path
\[
\widetilde\gamma
=
(\widetilde r_1,\ldots,\widetilde r_m),
\]
extend this componentwise:
\[
\boxed{
\pi_{\rm occ\to val}
(\widetilde\gamma)
=
(r_1,\ldots,r_m).
}
\]

Occurrence composability requires both carrier-value composability and
occurrence-address composability. Therefore forgetting addresses preserves
value composability:
\[
\boxed{
\widetilde\gamma
\text{ occurrence-composable}
\Longrightarrow
\pi_{\rm occ\to val}(\widetilde\gamma)
\text{ value-composable}.
}
\]

For a consistent occurrence-to-carrier assignment, occurrence closure also
implies value closure:
\[
\boxed{
\omega_m=\omega_0
\Longrightarrow
a_m=a_0.
}
\]
The converse is false. The singleton self-relation step
\[
a_{\varnothing}
\xrightarrow{r}
a_{-}
\]
projects to
\[
r:a\to a,
\]
which is value-closed, while
\[
\varnothing\neq(-)
\]
so the occurrence path remains open.

Thus
\[
\boxed{
\text{occurrence-closed}
\Rightarrow
\text{value-closed},
\qquad
\text{value-closed}
\not\Rightarrow
\text{occurrence-closed}.
}
\]

The executable kernel exposes this projection explicitly through
\texttt{forget\_relation\_occurrence} and
\texttt{forget\_occurrence\_path}.

\subsection{Value-level closure}

The relation-value path is carrier-closed when
\[
\boxed{
a_m=a_0.
}
\]
For such a path define the value-level return transport
\[
\boxed{
\mathcal H^{\mathrm{val}}_{\gamma}:=T_{\gamma}
}
\]
and the state-dependent residual
\[
\boxed{
\varepsilon^{\mathrm{val}}_{\gamma}(X)
=
\left\|
\mathcal H^{\mathrm{val}}_{\gamma}X-X
\right\|.
}
\]

This closure notion forgets path-labelled occurrence identity. It is therefore
sufficient for ordinary relation-value holonomy, but not for branch-aware
refinement holonomy.

\subsection{Occurrence-level closure}

An occurrence-aware relation step carries both the relation value and its
source/target occurrence addresses:
\[
\tilde r_k
=
\bigl(
r_k,
\omega_{k-1},
\omega_k
\bigr).
\]
The occurrence-aware path is
\[
\widetilde\gamma
=
(\tilde r_1,\ldots,\tilde r_m),
\]
with carrier composability and occurrence composability required
simultaneously.

Occurrence closure is
\[
\boxed{
\omega_m=\omega_0.
}
\]
With a consistent occurrence-to-carrier assignment, this implies carrier
closure. The converse is false.

The minimal counterexample is the singleton refinement step
\[
a_{\varnothing}
\xrightarrow{r}
a_{-}.
\]
After forgetting occurrence address, its relation value is
\[
r:a\to a,
\]
so the value path is carrier-closed. But
\[
\varnothing\neq(-),
\]
hence the occurrence path is open.

Therefore
\[
\boxed{
\text{carrier-closed}
\not\Rightarrow
\text{occurrence-closed}.
}
\]

Only when both close do we define branch-aware occurrence holonomy:
\[
\boxed{
\mathcal H^{\mathrm{occ}}_{\widetilde\gamma}
:=
T_{\widetilde\gamma},
\qquad
\omega_m=\omega_0.
}
\]
Its residual is
\[
\boxed{
\varepsilon^{\mathrm{occ}}_{\widetilde\gamma}(X)
=
\left\|
\mathcal H^{\mathrm{occ}}_{\widetilde\gamma}X-X
\right\|.
}
\]

The executable kernel represents these two levels separately:
\texttt{RelationPath}/\texttt{TransportPath} at value level, and
\texttt{RelationOccurrence}/\texttt{OccurrenceRelationPath}/
\texttt{OccurrenceTransportPath} at occurrence level.

\subsection{Transport composition defect}

When both a direct transport and a two-step transport are available, define
\[
\boxed{
\Delta_T(r_2,r_1;X)
=
\left\|
T_{r_2\circ r_1}X
-
T_{r_2}\bigl(T_{r_1}X\bigr)
\right\|.
}
\]
The zero-defect case is functorial transport on that composition. A non-zero
value records path/composition dependence rather than being discarded as an
implementation error.

\section{One-axiom closure candidate}

The current canonical object-level foundation uses two explicit axioms under
the prior model-formation rule META0:

\boxed{
\mathrm{META0}
\;\triangleright\;
(\mathrm{RA0}+\mathrm{RR1}).

The finite independence witnesses show that the original RA0 is too weak to

\[
\boxed{\mathrm{RA0}\not\Rightarrow\mathrm{RR1}.}

\boxed{
\mathrm{RA0}^{*}:
\text{every admitted carrier hosts an admitted non-degenerate binary distinction}

together with the closure clause that the two selected endpoint occurrences
are themselves admitted carriers.

by the two ordered occurrence slots \((-),(+)\), so
\[
D(a)=(a,a)
\]
is a valid hosted binary occurrence distinction. If several admissible
binary distinctions are hosted by the same carrier, any one witness is
sufficient for the finite-depth induction below. The executable reference
model chooses a lexicographically first endpoint pair solely to make its
unfolding deterministic; that selector is not part of RA0*.

\omega\in\{-1,+1\}^{n}.

If \(p_{\omega}\) is admitted, RA0* supplies

=
\bigl(

and both endpoints are admitted. By induction on \(n\), for every finite

\[
\boxed{

\qquad
0\le n\le N,
}
\]
is generated. Hence
\[
\boxed{
\mathrm{RA0}^{*}\Rightarrow\mathrm{RR1}
}
\]
in the path-labelled occurrence semantics.

\subsection{Relationally bound reduction candidate}

The candidate RA0* above supplies recursive distinction structure but does not

\qquad

The admitted carrier hosts the required binary occurrence distinction, so the

\boxed{

}
\]
The witness is non-empty, so the failure is not due to vacuous truth.

Therefore RA0* proves RR1 but not RA0 in the current language.

Define a stronger relationally bound distinction by equipping the two branch

\qquad

The corresponding stronger candidate is denoted

\boxed{
\mathrm{RA0}^{\mathrm{rel}*}
}

and is represented in the executable claim ledger by

\subsection{Forgetful projection to the plain distinction candidate}

A relationally bound binary distinction contains all data of a plain binary
occurrence distinction plus explicit branch-relation occurrences. Forgetting
only those relation labels defines a projection

\mathrm{RA0}^{\mathrm{rel}*}\text{-models}
\longrightarrow
\mathrm{RA0}^{*}\text{-models}.

It preserves the admitted carrier set and the complete path-labelled

\boxed{
\mathrm{RA0}^{\mathrm{rel}*}
\Rightarrow
\mathrm{RA0}^{*}.

Since the previous theorem gives

\mathrm{RA0}^{*}\Rightarrow\mathrm{RR1},

the recursive-closure implication also factors as
\[
\mathrm{RA0}^{\mathrm{rel}*}
\Rightarrow
\mathrm{RA0}^{*}
\Rightarrow
\mathrm{RR1}.
\]

Every admitted host now has primitive relational incidence. Therefore
\[
\boxed{
\mathrm{RA0}^{\mathrm{rel}*}
\Rightarrow
\mathrm{RA0}.
}
\]

The same endpoint-admissibility and finite-depth induction used above gives
\[
\boxed{
\mathrm{RA0}^{\mathrm{rel}*}
\Rightarrow
\mathrm{RR1}.

Consequently

\boxed{
\mathrm{RA0}^{\mathrm{rel}*}

\mathrm{RA0}+\mathrm{RR1}.

The converse fails in the expanded language. Consider the singleton raw

The proposed one-object-level-axiom reduction is therefore a strict

\;\triangleright\;

The singleton executable witness is

\qquad

The two branch-relation occurrences remain distinct by branch slot although
their source and target carrier labels coincide.

\subsection{Relation occurrences versus relation values}

A branch-relation occurrence carries the binary branch slot as part of its
identity:
\[
o=(\epsilon,r,s,t),
\qquad
\epsilon\in\{-1,+1\}.
\]
Forgetting only that occurrence slot yields the underlying typed relation
value:
\[
\boxed{
\pi_{\mathrm{rel}}(\epsilon,r,s,t)
=
(s,t,r).

The projection need not be injective. In particular,

\qquad

satisfy
\[
o_-\neq o_+,
\qquad
\pi_{\mathrm{rel}}(o_-)
=
\pi_{\mathrm{rel}}(o_+).

Thus branch identity belongs to the occurrence layer rather than to the
underlying relation value itself. The executable kernel preserves this
distinction and can materialize the projected value as a core
\texttt{TypedRelation}.

\subsection{Singleton cardinality minimality}

Hence the lower bound is attained and

\boxed{
\min_{\mathfrak M\models

The claim ledger records the lower bound, the explicit singleton witness, and

\subsection{Minimal underlying relation-value cardinality}

This is a metatheoretic statement about the relational signature, not a

\subsection{Occurrence growth from a singleton carrier}

Carrier cardinality and occurrence cardinality are distinct invariants. Under
binary recursive refinement, the number of path-labelled occurrences at
exact depth \(n\) is
\[
|V_n|=2^n,
\qquad
V_n=\{-1,+1\}^{n}.
\]
Hence the total number of occurrences through depth \(N\) is
\[
\boxed{
|V_{\le N}|
=
\sum_{n=0}^{N}2^n
=
2^{N+1}-1.
}
\]

The executable kernel exposes the same formula as
\texttt{binary\_occurrence\_count\_through\_depth}.

The full address set over all finite depths is
\[
V_{<\omega}
=
\{-1,+1\}^{<\omega}.
\]
It is countably infinite. A constructive bijection with \(\mathbb N\) is
obtained by encoding \(-1\mapsto0\), \(+1\mapsto1\) and setting
\[
\boxed{
\rho(\omega)
=
2^{|\omega|}-1
+
\operatorname{bin}(\omega).
}
\]
Words are therefore ordered first by length and then by binary index. The
inverse map is also explicit; the reference kernel implements the pair
\texttt{finite\_word\_rank}/\texttt{finite\_word\_unrank}.

Thus a singleton carrier model can satisfy
\[
|\operatorname{Adm}|=1
\]
while its relational occurrence structure grows without bound:
\[
\boxed{
|\operatorname{Adm}|=1
\quad\not\Rightarrow\quad
|V_{<\omega}|=1.
}
\]
More precisely,
\[
|V_{<\omega}|=\aleph_0.
\]
This is a combinatorial statement about path-labelled relational occurrences,
not a physical infinity claim.

\subsection{Ideal boundary of infinite branch sequences}

The finite occurrence-address set
\[
B^{<\omega}
=
\{-1,+1\}^{<\omega}
\]
is countably infinite. Its ideal path boundary is a different object:
\[
\boxed{
\partial V
=
B^\omega
=
\{-1,+1\}^{\mathbb N}.
}
\]

For a finite word \(u\in B^n\), define the prefix cylinder
\[
[u]
=
\{
\xi\in B^\omega:
u\preceq\xi
\}.
\]
At exact prefix depth \(n\), the boundary is partitioned into
\[
\boxed{
2^n
}
\]
such cylinders. The executable helpers
\texttt{binary\_words\_at\_depth} and
\texttt{binary\_boundary\_cylinder\_count} audit this finite prefix basis.

The map
\[
\xi=(\xi_0,\xi_1,\ldots)
\longmapsto
S_\xi
=
\{
n\in\mathbb N:
\xi_n=+1
\}
\]
is a bijection between \(B^\omega\) and the power set
\(\mathcal P(\mathbb N)\). Therefore
\[
\boxed{
|\partial V|
=
2^{\aleph_0}.
}
\]

This does not contradict the countability of finite occurrence addresses:
\[
|B^{<\omega}|=\aleph_0,
\qquad
|B^\omega|=2^{\aleph_0}.
\]

Under RR1, for every ideal sequence \(\xi\in\partial V\), every finite
prefix
\[
\xi\!\upharpoonright_n
\]
is realized by a path-labelled occurrence. Thus each ideal boundary point
determines a coherent chain
\[
p_{\varnothing},
\quad
p_{\xi\upharpoonright_1},
\quad
p_{\xi\upharpoonright_2},
\quad\ldots
\]
of finite occurrences.

RR1 does not, however, assert the existence of a limit carrier
\[
p_\xi
\]
for an infinite address. Such a completion would require additional
topological or geometric structure. Consequently
\[
\boxed{
\text{uncountable ideal boundary}
\not\Rightarrow
\text{uncountably many admitted carriers}.
}
\]

\subsection{Free monoid of occurrence addresses}

The finite occurrence-address space
\[
B^*=\{-1,+1\}^{*}
\]
has a canonical algebraic structure under word concatenation. With the empty
word \(\varnothing\) as identity, \(B^*\) is the free monoid on the two
branch generators \(-1\) and \(+1\).

Carrier values and occurrence addresses are distinct sorts:
\[
\boxed{
a\neq\omega
\quad\text{as semantic types.}
}
\]
The carrier value \(a\) identifies the underlying relational carrier,
whereas \(\omega\in B^*\) identifies a path-labelled occurrence of such a
value in a recursive unfolding.

For \(\omega,u\in B^*\), define the regular right action
\[
\boxed{
\omega\cdot u
=
\omega u.
}
\]
Then
\[
\omega\cdot\varnothing=\omega
\]
and
\[
\boxed{
(\omega\cdot u)\cdot v
=
\omega\cdot(uv).
}
\]

The executable kernel represents this canonical address algebra through
\texttt{OccurrenceAddress}. In particular,
\texttt{OccurrenceAddress.advance} realizes concatenation and
\texttt{OccurrenceAddress.refine} realizes the two one-generator extensions.

The word-length map
\[
\ell:B^*\to\mathbb N,
\qquad
\ell(\omega)=|\omega|
\]
is additive:
\[
\boxed{
\ell(\omega u)
=
\ell(\omega)+|u|.
}
\]
Thus the finite occurrence-address space is naturally \(\mathbb N\)-graded.

RR1 is a separate closure statement: it says that, from an admitted root,
every finite address word is represented by an actual path-labelled
relational occurrence. Consequently
\[
\boxed{
\text{address algebra}
\neq
\text{admission/realization of every address}.
}
\]

\subsection{Reference embedding into binary point coordinates}

Existing CP1/refinement realizations retain a binary reference coordinate on
\texttt{RelationalPoint}. The relation between the two semantic sorts is
therefore represented explicitly by an injective reference map
\[
\boxed{
\iota:
B^*
\hookrightarrow
P_{\rm ref},
\qquad
\iota(\omega)=p_\omega.
}
\]

The executable function
\[
\texttt{reference\_point\_from\_occurrence}
\]
implements \(\iota\).

This is a reference realization, not a type identity:
\[
\boxed{
\operatorname{OccurrenceAddress}
\not\equiv
\operatorname{RelationalPoint}.
}
\]
The fact that the reference point coordinate may numerically store the same
binary tuple as \(\omega\) does not identify carrier/reference-coordinate
values with branch-occurrence identity.

\subsection{Prefix order, meet, and canonical tree metric}

The free-monoid address structure carries a canonical rooted-tree order. For
finite words \(u,v\in B^*\), define
\[
\boxed{
u\preceq v
\Longleftrightarrow
\exists w\in B^*:\ v=uw.
}
\]
This is the ancestor/prefix order.

Any two finite words possess a greatest lower bound in this order: their
longest common prefix,
\[
\boxed{
u\wedge v
=
\operatorname{LCP}(u,v).
}
\]
Hence the finite occurrence addresses form a rooted meet-semilattice.

Using the word-length grading, define
\[
\boxed{
d_T(u,v)
=
|u|+|v|-2|u\wedge v|.
}
\]
This is the number of tree edges in the unique geodesic from \(u\) to
\(v\): move from \(u\) upward to \(u\wedge v\), then downward to \(v\).
Consequently
\[
d_T(u,v)\ge0,
\qquad
d_T(u,v)=0\Longleftrightarrow u=v,
\]
\[
d_T(u,v)=d_T(v,u),
\]
and the triangle inequality holds. Thus
\[
\boxed{
(B^*,d_T)
\text{ is a metric space.}
}
\]

The reference kernel implements the order, meet, and metric through
\texttt{OccurrenceAddress.is\_prefix\_of},
\texttt{OccurrenceAddress.meet}, and
\texttt{OccurrenceAddress.tree\_distance}.

This is a combinatorial metric forced by the occurrence-address structure.
It is not identified with a physical distance, the Fubini--Study metric, a
Hilbert norm, a Minkowski metric, or any later geometric realization.

The algebraic address monoid exists independently of RR1. RR1 supplies the
additional closure statement that, from an admitted root, every finite word
\(u\in B^*\) is realized by an actual path-labelled relational occurrence.
Thus
\[
\boxed{
\text{address algebra}
\neq
\text{admission/realization of every address}.
}
\]

This is a genuine strengthening: it adds distinction-to-relation binding.
It is executable and theorem-tested but is not promoted as canonical.

This is a genuine strengthening of RA0, not a proof from its old wording.
RA0* explicitly adds binary non-degeneracy and endpoint admissibility. Those
clauses are precisely what makes the induction valid.

The underlying carrier presentation may be even smaller than a two-cycle. The
singleton witness
\[
D(a)=(a,a)
\]
already satisfies RA0* at the occurrence level and unfolds as
\[
a_{\varnothing},
\quad
a_-,a_+,
\quad
a_{--},a_{-+},a_{+-},a_{++},
\quad\ldots
\]
with distinct path-labelled occurrences carrying the same underlying label.
A two-cycle such as
\[
D(a)=(a,b),
\qquad
D(b)=(a,b)
\]
is another admissible finite presentation. Thus recursive relational structure
does not by itself imply ontically fresh carrier identities:

\section{Canonical normalization and reduction}

The executable kernel now includes a fail-closed canonicalization layer whose
purpose is to reduce representational redundancy without erasing semantic
distinctions.

For an executable value \(X\), the strict canonical form is represented
schematically as
\[
\mathcal N_0(X)
=
\bigl(\operatorname{type}(X),\operatorname{payload}(X)\bigr).
\]
Concrete type is therefore part of strict identity. In particular,
\[
\boxed{
\mathcal N_0\!\left(\operatorname{OccurrenceAddress}(\omega)\right)
\neq
\mathcal N_0\!\left(\operatorname{RelationalPoint}(\omega)\right)
}
\]
even when both display the same binary coordinate word.

The strict normalizer is idempotent by construction:
\[
\boxed{
\mathcal N_0(\mathcal N_0(X))=\mathcal N_0(X).
}
\]

A non-trivial reduction rule carries two independent classifications. Its
semantic relation kind belongs to
\[
\{
\mathrm{IDENTITY},
\mathrm{EXACT\_EQUIVALENCE},
\mathrm{ISOMORPHISM},
\mathrm{REFERENCE\_REPRESENTATION},
\mathrm{FORGETFUL\_PROJECTION},
\mathrm{APPROXIMATION}

\]
while its information effect belongs to
\[
\{
\mathrm{LOSSLESS},
\mathrm{LOSSY},
\mathrm{UNKNOWN}
\}.
\]
A rule declared LOSSLESS must supply an explicit inverse. An isomorphism rule
must be both LOSSLESS and explicitly invertible.

reference engine uses

\Rightarrow
\text{stop},
\qquad
|A(X)|=1
\Rightarrow
\text{apply the unique rule},

while
\[
\boxed{

\mathrm{AMBIGUOUS\_REDUCTION}.

Registration order therefore carries no hidden mathematical authority.
Repeated exact canonical keys are rejected as reduction cycles.

\subsection{Termination and finite confluence}

A reduction cycle guard is operationally necessary but is not a proof that all
reduction paths terminate. The kernel therefore permits an explicit
fixed-dimensional measure
\[
\mu:X\to\mathbb N^k,
\qquad
1\le k<\infty,
\]
ordered lexicographically. Every admitted ordered step must satisfy
\[
\boxed{
\mu(X_{n+1})<_{\mathrm{lex}}\mu(X_n).
}
\]
Since lexicographic order on fixed finite-dimensional \(\mathbb N^k\) is
well-founded, strict descent on every step implies termination of the
corresponding reduction sequence.

The measure is supplied rather than inferred. A variable-dimensional measure
is rejected because it does not provide the same well-founded certificate.

A separate finite confluence auditor explores every applicable rule branch from
one supplied start state up to a finite depth. Its result is one of
\[
\begin{aligned}
&\mathrm{UNIQUE\_NORMAL\_FORM},\\
&\mathrm{MULTIPLE\_NORMAL\_FORMS},\\
&\mathrm{CYCLE\_DETECTED},\\
&\mathrm{BOUNDED\_INCOMPLETE}.
\end{aligned}
\]
This distinguishes a concrete bounded confluence witness from a global
Church--Rosser theorem. The latter is not claimed by the current kernel.
